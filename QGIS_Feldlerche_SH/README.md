# GIS-basierte PV-Standortanalyse im Raum Lübeck

## Projektziel

Ziel des Projekts war die Identifikation potenziell geeigneter Photovoltaikflächen im Raum Lübeck unter Berücksichtigung von Artenschutz, bestehender Infrastruktur und vorhandenen Nutzungen.

## Verwendete Daten

- GBIF Feldlerchen-Beobachtungen
- OpenStreetMap (OSM)
- Geofabrik
- Strominfrastruktur (Umspannwerke und Leitungen)

## Methodik

1. Import und Bereinigung der Feldlerchen-Daten
2. Identifikation von Hotspots mittels räumlicher Analyse
3. Erzeugung von Ausschlussflächen
4. Integration von Infrastruktur
5. Ermittlung potenzieller PV-Flächen mittels GIS-Overlay- und Differenzanalysen

## Ergebnis

Die Analyse liefert potenzielle PV-Standorte im Raum Lübeck, die aus Sicht der verwendeten Daten eine geringe Konfliktwahrscheinlichkeit mit Feldlerchen-Hotspots aufweisen und gleichzeitig infrastrukturell erreichbar sind.

## Hinweise

Die Analyse stellt eine GIS-basierte Voranalyse dar und ersetzt keine rechtliche, naturschutzfachliche oder planungsrechtliche Prüfung.
